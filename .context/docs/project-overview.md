# Project overview

`pp-leads-brasil` é uma base local para inteligência de leads brasileiros, com foco em CNPJs, empresas, contatos e qualificação comercial.

Nesta pasta, o uso principal foi especializado para a OrganizeJr, empresa júnior de Psicologia Organizacional da UNEB Salvador. Lucas Camilo Carvalho usa o repositório como área de trabalho comercial: coloca demandas em Excel, texto e documentos; os agentes devem transformar esses insumos em pesquisa de leads, enriquecimento por `pp-leads-brasil`, ranking por ICP e abordagem personalizada.

O contexto comercial da OrganizeJr vive em `.context/docs/organizejr-commercial-context.md`. A skill local que operacionaliza o fluxo vive em `.context/skills/organizejr-pp-leads/SKILL.md`.
